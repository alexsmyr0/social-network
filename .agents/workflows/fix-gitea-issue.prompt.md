# Social-network issue workflow

Confirm the issue and repository, then use the [active requirements](../../docs/social-network/requirements.md), [tracker](../../docs/social-network/ticket-tracker.md) and [agent guide](../../AGENTS.md). Reproduce a code defect when relevant, implement the scoped change, run the applicable verification gate, and use the [current PR template](../../.github/pull_request_template.md). The former forum Gitea issue assignments and branch rules are archived history.
